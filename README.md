# 🧠 AI Lost & Found

An AI-powered Lost & Found platform using smart matching, visual search, maps, and a futuristic AI interface.

## ✨ Features

- 🤖 AI-powered item matching
- 🔍 Visual search
- 📍 Map integration
- 🧠 Smart detection
- 📷 Image upload
- 🔒 Secure reporting
- ⚡ Futuristic animated UI

## 🛠 Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Flask
- Python

Database:
- SQLite

## 🚀 Run Project

Install requirements:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

Open:

```txt
http://127.0.0.1:5000
```
